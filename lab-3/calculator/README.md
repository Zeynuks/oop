# Инструкция по сборке и генерации UML-диаграмм

---

## Порядок действий

Выполняйте эти команды последовательно из корневой директории проекта:

### 1. Подготовка и сборка
Создаем директорию сборки и генерируем базу данных компиляции (`compile_commands.json`).

```bash
cmake -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
```
### 2. Генерация описания диаграмм
Запускаем clang-uml для анализа кода и создания текстового описания схемы.

```Bash
clang-uml --query-driver=clang++ --generate-from-template class_calc
```
### 3. Отрисовка графики
Переходим в директорию с диаграммами и конвертируем .puml в изображение.

```Bash
cd ../diagrams
plantuml class_calc.puml
```
